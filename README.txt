PHONG TRANH - GITHUB PAGES

1. Upload toàn bộ nội dung trong thư mục này lên repository GitHub.
2. Giữ nguyên file index.html và thư mục assets.
3. Vào Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Không đổi tên hoặc di chuyển thư mục assets nếu chưa sửa lại đường dẫn trong index.html.
